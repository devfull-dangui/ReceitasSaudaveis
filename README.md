# 🚀 Desafio de Projeto: Landing Page (One Page) - DIO

Projeto prático desenvolvido para o curso de UX/UI Design da **DIO (Digital Innovation One)**. O objetivo foi criar uma landing page estruturada de média/alta fidelidade aplicando leis de usabilidade e psicologia do design.

---

## 📐 Estrutura do Protótipo (1440px)
A página foi desenhada no Figma seguindo uma ordem lógica de conversão:
1. **Header:** Logotipo, menu central de navegação e CTA de Login/Entrar.
2. **Hero Section:** Título principal de impacto, subtítulo contextual e CTA primário.
3. **Diferenciais (3 Colunas):** Cards visuais com os pilares do produto.
4. **Seção de Conceito (Split Screen):** Bloco de texto descritivo alinhado a uma imagem de suporte.
5. **Destaques Secundários (2 Colunas):** Segmentação de conteúdo com imagens amplas.
6. **Depoimentos (Prova Social):** 3 cards com foto e feedback de usuários.
7. **Footer / CTA Final:** Rodapé com links institucionais e última chamada para ação.

---

## 🧠 Fundamentação em UX/UI (Leis Aplicadas)

* **Critérios Ergonômicos de Bastien e Scapin:** Aplicados na *Orientação e Condução* (leitura vertical fluida e cabeçalhos claros) e na *Carga de Trabalho* (textos curtos e diretos para evitar sobrecarga cognitiva).
* **Heurísticas de Nielsen (#4 e #6):** O layout respeita os padrões da web (links e botões onde o usuário espera encontrar), promovendo o *Reconhecimento em vez de Evocação*.
* **Lei da Proximidade (Gestalt):** Elementos relacionados (imagens, títulos e botões dos cards) foram agrupados próximos para que o cérebro do usuário os interprete como uma única unidade de informação.
* **Efeito de Posição Serial:** Os CTAs e as informações mais importantes foram fixados no topo e no final da página, onde a retenção de atenção do usuário é estatisticamente maior.
